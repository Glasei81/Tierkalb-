E-Mail SMTP
📖 Einrichtungsanleitung (Gmail) anzeigen
1. Google-Konto → Sicherheit → 2-Faktor-Authentifizierung aktivieren
2. Sicherheit → App-Passwörter → Neues App-Passwort → "Mail" → 16-stelligen Code kopieren
3. SMTP: smtp.gmail.com, Port: 587
4. Benutzername: deine Gmail-Adresse, Passwort: der 16-stellige Code aus Schritt 2
Wichtig: Gib hier niemals dein normales Gmail-Passwort ein — nur App-Passwörter!
